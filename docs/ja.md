# Cthangover: Starter Party — プレイヤーの最初の仲間

この小さな MOD は、Cthangover のニューゲームに初期状態を与えます:パーティに入ったマラオと、スキルコレクションに入ったスキル「奴隷商人」です。入っているのはこのコードだけで、キャラクターとスキルそのものはベースゲームとスキルエンジンのデータです。

## 新しいプレイヤーの手元にあるもの

Cthangover 冒頭のキャラクターパネル — パーティメンバーはマラオ一人、アクション二つと空きスロット一つ:

![キャラクターアクションパネル:パーティ 1、マラオ(テンプレート 2、HP 16/16、AP 1、ATK 5、DEF 0)に「通常攻撃」と「防御」、3 つ目のスロットは空き。](assets/party.jpg)

スキルパネル — スキルは一つ、奴隷商人:

![スキルパネル:コレクションにはエピックのパッシブスキル「奴隷商人」が一つ、「勧誘の確率 +10%」、説明は「倒した敵を基本確率 10% で奴隷にできる。奴隷の食い扶持はあなた持ち。」、コレクション効果は勧誘の確率 +10%。](assets/skills.jpg)

奴隷商人があるからこそ、プレイヤーは倒した敵を捕らえられます(Recruiting を参照):これがなければ敵は誰も加わりません。

## いつ動くか

- ゲームの MOD が揃うと、この MOD はキャラクター `Marao` をパーティに加え、スキル `slave_master` を与えます。
- **ニューゲーム**を始めるたびに同じことを繰り返します。ニューゲームはまずパーティを空にするからです。
- セーブのロードはパーティとスキルを保存済みのものへ置き換えます。どちらの処理も複数回走っても安全です。マラオが二重に追加されることも、スキルが二重に与えられることもありません。

## 初期状態を変えるには

- 別の MOD も同じやり方で初期キャラクターを増やせます:MOD が揃ったときに自分のキャラクターをパーティへ加える C# の初期化子です。
- マラオやスキルなしで始めたいなら、この MOD をゲームのコレクションに入れず、自分の MOD でパーティを用意します。

## 既知の問題

- 奴隷商人のカードに画像がありません:スキルの画像が欠けています。
- カードと説明は「勧誘の確率 +10%」をうたっていますが、このボーナスを読むコードは存在せず、捕獲判定は敵自身の確率だけを使います。
