# Cthangover: Starter Party — 玩家的初始伙伴

这个小模组为 Cthangover 的新游戏提供初始状态：队伍中的马劳，以及技能收藏里的“奴隶贩子”。它只包含这段代码；角色和技能本身则是基础游戏和技能引擎的数据。

## 新玩家一开始有什么

Cthangover 开局时的角色面板——队伍里只有马劳一人，带两个动作和一个空位：

![角色动作面板：队伍 1，马劳（模板 2，HP 16/16，AP 1，ATK 5，DEF 0），动作为“普通攻击”和“防御”，第三个栏位为空。](assets/party.jpg)

技能面板——只有一个技能“奴隶贩子”：

![技能面板：收藏中有一个史诗级被动技能“奴隶贩子”，“+10% 招募几率”，描述为“能以 10% 的基础概率奴役被击败的敌人。奴隶的生计由你负担。”，收藏效果为 +10% 招募几率。](assets/skills.jpg)

“奴隶贩子”正是玩家捕获被击败敌人的手段（见 Recruiting 模组）：没有它，任何敌人都无法加入。

## 什么时候生效

- 游戏的模组就绪后，模组把角色 `Marao` 加入队伍，并授予技能 `slave_master`。
- 每次开始**新游戏**都会再执行一遍，因为新游戏会先清空队伍。
- 读取存档会用存档内容替换队伍和技能。这两个步骤重复执行也安全：马劳不会被加两次，技能也不会被授予两次。

## 想改初始配置

- 其他模组可以用同样的方式添加更多初始角色：一个 C# 初始化器，在模组就绪时把自己的角色加进队伍。
- 想在没有马劳或没有该技能的情况下开局，就不要把这个模组放进游戏合集，改在自己的模组里组建队伍。
